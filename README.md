# Minimega

Fabric mod project reconstructed from the extracted Minimega sources and resources.

## Build

```bash
./gradlew build
```

On Windows:

```powershell
.\gradlew.bat build
```

The project targets Minecraft `26.1`, Fabric Loader `0.19.1`, Fabric API `0.145.4+26.1`, and Java `25`, as declared by the extracted `fabric.mod.json`.
